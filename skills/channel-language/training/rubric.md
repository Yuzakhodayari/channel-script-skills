# Scoring rubric

- L1: 1 point per tell found, -0.5 per false flag. % = found/total.
- L2: exact word = 1, same function class (connector vs content) = 0.5.
- L3: correct with the right signal named = 1, correct without a reason = 0.5.
- L4/L5 (0-5 each, average): contractions, openers at mode rate, rhythm (SD 8+), fillers/hedges, specificity, plain words, viewer address, punctuation, lean fidelity, read-aloud. 5 = indistinguishable from the gold when read aloud.
