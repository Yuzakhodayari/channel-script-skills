# Exam rubric

- A, B: 1 if correct, else 0.
- C: score = 0.35 x tell-free (1/(1+tells)) + 0.35 x token-F1 vs gold + 0.30 x fingerprint (contraction count and sentence-length SD vs gold). Pass at 0.85 or above.
- Every 10 exams: the dominant miss types activate a new rule. The rule's lesson is written into SKILL.md (Standing lessons) and references/criteria.md (Exam-derived lessons).
