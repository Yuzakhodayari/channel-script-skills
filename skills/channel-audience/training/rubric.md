# Scoring rubric (audience drills)

| level | item | scoring |
|---|---|---|
| L1 | device spotting | 1 = exact device; 0.5 = right category letter; else 0 |
| L2 | hook-vs-middle, close-vs-middle | 1 / 0, plus a one-line reason naming the cue (self-contained? "you"+future?) |
| L3 | real-vs-flattened, creator | 1 / 0 |
| L4 | punch-up rewrite | +1 per device restored that the original had (address, question, momentum opener, intensifier), −1 per device that overshoots criteria norms; compare with the original |
| L5 | production | the 11-item self-check in SKILL.md (0-2 each, /22) + re-hook gap and "you" density computed by hand on your text |
