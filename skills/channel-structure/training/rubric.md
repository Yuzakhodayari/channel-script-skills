# Scoring rubric (structure drills)

| level | item | scoring |
|---|---|---|
| L1 | beat label | 1 = exact label; 0.5 = the right family (SECTION TURN vs QUESTION TURN; CONCLUSION vs FINAL LINE); else 0 |
| L2 | position % | 1 = within ±10 points; 0.5 = within ±20; else 0. Ordering items: pairwise order accuracy |
| L3 | opener / mode MCQ | 1 / 0 |
| L4 | outline reconstruction | 4 points: hook end ±3%, first sponsor ±10% (or correctly "none"), conclusion ±8%, turns ±2. Then list one structural difference between your outline and the gold map and say which is better for the topic |
| L5 | production | the 10-item self-check in SKILL.md (0-2 each, /20) + every number checked against criteria.md tests |
